# IEEE writing, typesetting, and review reference

## Manuscript writing

- Make each paragraph serve one logical job and make transitions carry technical meaning.
- State related work specifically before identifying its limitation; do not force an artificial one-to-one comparison with the present work.
- Keep terminology and notation stable across abstract, system model, optimization, algorithms, figures, and simulations.
- Number only equations that need cross-reference. Define symbols near first use and use punctuation/grammar that reads through equations.
- Keep figure and table captions self-contained; define baselines and parameters before interpreting them.

## Revision package

For each advisor comment or reviewer issue, record: source location, issue type, technical impact, proposed change, exact affected files/equations/figures, evidence, user decision, and verification after revision.

## Reviewer gate

Use `academic-paper-reviewer` as a role-separated review panel when it is available. Separate its observations from validated facts. Do not call its review complete until every blocking item is either fixed, explicitly deferred, or justified in the disposition record.

## Submission gate

Check manuscript version freeze, author/affiliation metadata, figures, citations, bibliography, auxiliary files, venue format constraints, data/code statements if required, cover letter, response letter, and upload checklist. Confirm the target venue requirements from an authoritative current source when they may have changed.
