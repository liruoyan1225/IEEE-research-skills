# IEEE 期刊写作风格档案

## 默认基线

- 语料范围：IEEE JSAC、TWC、TCOM、TSP、Communications Surveys & Tutorials、Proceedings of the IEEE 的代表性论文。
- 规则来源：`references/ieee-journal-style-corpus.md` 与 `references/style-profile.md`。
- 使用边界：用于组织工程论文论证、系统模型、优化算法和仿真结果；不是 IEEE 官方规范，也不模仿单一作者。
